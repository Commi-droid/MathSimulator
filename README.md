# Дидактические карточки – интерактивный математический тренажёр

Веб-приложение к методической разработке **«Использование дидактических карточек для совершенствования вычислительной культуры обучающихся (5–9 классы)»**.

Тренажёр визуализирует структуру чисел и алгебраических выражений через механику цвето-ассоциативного конструктора.

### Модули тренажёра:
1. **5–6 класс: НОД и НОК** – разложение чисел на простые цветовые множители, наглядный поиск пересечения и объединения множеств.
2. **7–9 класс: Свойства степеней** – интерактивная «гармошка» множителей для умножения, деления и возведения степени в степень.
3. **8 класс: Вынесение множителя из-под знака корня** – попарный выход простых множителей из-под радикала.
4. **7–9 класс: Алгебраические дроби и ФСУ** – защита от сокращения отдельных слагаемых («монолит сложения») и разложение на множители.

### Управление и запуск:
* Работает полностью автономно в любом браузере (один файл `index.html`, не требует интернета и внешних библиотек).
* Поддерживает перетаскивание (`Drag-and-Drop`), клики мышью/касания на интерактивной доске и горячие клавиши (`1–4` – выбор модуля, `→` / `PageDown` – следующий шаг, `R` – сброс примера).
